## Implicit rejection (FIPS 203 section 6, Algorithm 18)

- Tampered-ciphertext trials across all three parameter sets: 2100 total; decapsulation returned success in 2100; shared secret equal to the valid secret in 0 (zero); deterministic implicit-rejection secret in 2100.
- Ciphertext-length check: the liboqs decaps API takes no length argument (OQS_KEM_decaps has no length parameter), so the FIPS 203 section 7.3 length check is the caller's responsibility; RFC 10024 section 4.2 requires the TLS client to perform it (finding F-05).
- Control (valid encaps/decaps): 600/600 secret matches.

Source: `src/implicit_reject.c`; logs `outputs/rejection-run1.log`,
`outputs/rejection-run2.log`; summary `outputs/rejection-summary.json`.
